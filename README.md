# TeaMaster 🍵

Jeu de cartes de thés et de tisanes : ouvre des sachets, complète ta collection, réponds au quiz de Fabien et retrouve Teapee le chat.

Tout le jeu tient dans `index.html` (aucun serveur, aucune installation). La progression est gardée dans le navigateur.

## Jouer depuis GitHub (gratuit)

1. Crée un dépôt **public** sur GitHub (bouton « New »), par exemple `teamaster`.
2. « uploading an existing file » : glisse **tout le contenu** de ce dossier (`index.html`, `config.js`, `.nojekyll`, `README.md`, `GUIDE.md`), puis « Commit changes ».
3. Dans le dépôt : **Settings → Pages → Build and deployment → Source : Deploy from a branch**, branche `main`, dossier `/ (root)`, puis Save.
4. Après 1 à 2 minutes, le jeu est en ligne à l'adresse `https://TON-PSEUDO.github.io/teamaster/` — c'est le lien à partager, il s'ouvre sur Safari, iPhone, Android et ordinateur.

(Les fichiers cachés comme `.nojekyll` ne se glissent pas toujours depuis le Finder : ce n'est pas grave, le jeu marche sans.)

## Jouer en local

Ouvre `index.html` dans Safari ou Chrome sur ordinateur.

## Comptes pseudo + mot de passe (facultatif)

Par défaut, mode invité : la progression reste sur l'appareil (avec un code de sauvegarde pour la transférer, dans Profil). Pour ajouter des comptes en ligne gratuits, suis `GUIDE.md` (étape 1 seulement) puis remplis `config.js`.
